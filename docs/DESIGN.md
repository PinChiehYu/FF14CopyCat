# 網頁使用流程與設計

本文件描述 FF14 CopyCat 網頁**給使用者的樣子**：使用流程、各區塊呈現什麼、如何操作、判定規則，以及待辦事項與設計變更紀錄。架構、程式實作、資料處理、驗證數據與部署見 [TECH_NOTES.md](TECH_NOTES.md)。

網站：https://pinchiehyu.github.io/FF14CopyCat/

## 網站目標

讓玩家把自己的 FFLogs 日誌與前輩的日誌並排比較，依 Boss 機制對齊兩場戰鬥，找出技能循環、減傷、走位與站位上的差異，並給出具體的改進建議。訪客不需要 FFLogs 帳號，貼上連結即可使用。

## 使用流程

輸入的兩個連結保存在本頁網址（`?mine=…&ref=…`），重新整理後自動還原，也可以直接把網址分享給別人。選好戰鬥與角色後，保存的連結會換成帶有該戰鬥與角色的連結（`?fight=…&source=…`），還原時不用重選；清空輸入框時一併移除。

### 從繁中服排名找參考日誌
參考日誌標題列右側有「從排名找」按鈕（選好我的日誌前停用，滑鼠提示說明原因），按下後在輸入框上方浮出面板，不推擠下方的戰鬥／角色欄位，兩邊日誌框的欄位保持對齊；點面板外或按 Esc 關閉（選單開著時 Esc 先關選單），搜尋結果保留：
- **範圍**：只找繁中服（泰坦、奧汀、利維坦、迦樓羅、伊弗利特、鳳凰、巴哈姆特）與我同一個 Boss、同難度、同職業的擊殺。FFLogs 不替繁中服排名，所以排名由本站自建：定時掃描 FFLogs 上的公開報告，收錄繁中服玩家的擊殺。私人報告不會收錄，資料需要時間累積。
- **PR**：每位玩家（名稱＋伺服器）只取 DPS 最好的一場，只和同 Boss、同難度、**同職業**的繁中服玩家比較（其他職業不列入人數與名次；同一人玩其他職業也分開計算），依 DPS 由高到低排出名次，PR＝勝過多少比例的玩家（第一名 100、最後一名 0）。用 DPS 而非 rDPS（FFLogs 不替繁中服計算 rDPS），所以與 FFLogs 網站上國際服的 PR 不能直接比較。
- **設定與結果**：輸入 PR 範圍（欄位標示為「武士 PR」等職業名稱，滑鼠提示說明只在該職業間計算；預設 90～100；下限不能高於上限，超出時離開輸入框會自動調回範圍內）後按「搜尋」，命中的紀錄（最多 20 筆，依名次由高到低）放在下拉選單中，每個選項為名次、PR、「玩家 @ 伺服器」、DPS、戰鬥長度，日期在滑鼠提示（手機寬度只顯示 PR、玩家、DPS）。選單上方一行「共 N 人，列出 M 筆」，完整說明（每人取最好的一場、依 DPS 排序）放在滑鼠提示，避免撐高輸入框。從選單選一筆就填入參考日誌（帶有該場戰鬥與角色）並關閉面板，選單保留顯示目前選的紀錄；重新搜尋或換了我的日誌時清空。
- **機制相同**（勾選框，滑鼠提示說明用途）：勾選後逐筆抓 Boss 施放、依時間軸對齊後與我比對，每個選項最後標示「機制相同」或「N 處不同」（只算同一時間施放不同技能的隨機變化，「只有一邊」多半是輸出差異造成，不算），並隱藏不同的。比對中的先顯示「比對中…」。隨機機制多的 Boss（例如呼嘯之劍）很難有完全相同的：全部比對完仍沒有時，改為依不同處由少到多列出，並在摘要列註明「無完全相同，依差異排序」。

1. **貼上兩個 FFLogs 報告連結**：左邊是「我的日誌」，右邊是「參考日誌（前輩）」。連結中的 `fight`、`source` 參數會被用來預選戰鬥與角色；輸入過程會等使用者停止輸入約 0.4 秒後才載入。
2. **選擇戰鬥與角色**：每份報告顯示戰鬥下拉選單（每列為 `#編號`、Boss 繁中名稱、戰鬥長度、擊殺／滅團徽章（綠／紅），各欄固定寬度、上下對齊，Boss 名稱與角色名稱的起點也對齊；滑鼠停留顯示英文名稱）與角色下拉選單（位置、角色名與職業繁中名稱徽章，徽章依職能上色：坦克藍、治療綠、輸出紅；不含極限技等假角色）。角色依隊伍位置排序：坦克 → 純治療（白魔、占星）→ 護盾治療（學者、賢者）→ 近戰 → 遠程物理 → 魔法，同組依職業名稱；標準的 2 坦 2 補 4 輸出隊伍會在名字前標上 MT／ST／H1／H2／D1～D4；**MT／ST 依實際坦 Boss 的情況**：承受 Boss 普通攻擊傷害較多的坦克為 MT（資料查到前坦克先不標位置），組成不標準時不標位置。參考日誌只列同職業時，位置仍依整隊判斷。下拉選單為自訂元件，可用滑鼠或鍵盤（上下鍵、Enter、Esc）操作。不顯示報告標題。選擇的優先順序：
   1. 使用者在下拉選單的手動選擇（換戰鬥時角色回到自動選擇）。
   2. 連結中的 `fight`、`source`。
   3. **參考日誌依「我的日誌」自動選擇**：戰鬥選單**只列與我同一個 Boss 的場次**，預設選最後一次擊殺（沒有擊殺則選最後一場）；連結指定的場次不是同一個 Boss 時不採用。報告中沒有同一個 Boss 時，戰鬥與角色選單都顯示「這份報告沒有 X」並停用（與沒有同職業時相同）。角色選單只列出該戰鬥中與我同職業者——**恰好一位時自動選取並鎖定**（選單右側以鎖頭圖示取代箭頭，滑鼠提示說明原因，文字與顏色維持正常不淡化，不能改選，也不受參考連結的 source 影響）；兩位以上時選單上顯示「這場戰鬥有 N 位 X，請選擇要比較的對象」，由使用者在其中選擇（連結的 source 是其中一位時預選）；沒有時**選單本身顯示「這場戰鬥沒有 X」並停用**。提示都顯示在選單上，不另外加說明列，避免版面變長。
   4. 都沒有時：戰鬥選最後一場，角色不選。

   目的：使用者通常只要貼上前輩的報告連結，其餘自動完成。
3. **檢查是否可比較**：兩場必須是同一個 Boss、同一職業，否則顯示原因（例如「兩位玩家的職業不同（毒蛇劍士 / 武士）」）。
4. **載入與顯示比較結果**：標題為「比較結果」，依序顯示下列區塊。技能名稱先以英文顯示，繁中名稱查到後自動替換。

## 比較結果頁面

### 摘要
- 以**表格**並列「我」與「參考」兩欄（欄標題以橘／藍區分），只列上方選單沒有的資訊：
  - **版本**：依戰鬥日期對照繁中服版本上線日期判斷的遊戲版本，例如「7.2」「7.25」（本工具只處理繁中服日誌）；兩邊不同時文字變色。兩邊版本不同、且有技能窗口規則因此不同時，表格下方列出「兩邊版本不同，技能窗口依各自版本的規則評分：無情（我 …／參考 …）」。
  - **rDPS**（第二列）：兩邊整場的 rDPS（FFLogs 計算；繁中服日誌不排名但仍有計算），我比參考少時以紅字標出差距「−N」；滑鼠提示為「rDPS＝DPS − 隊友 Buff 加成 ＋ 自己 Buff 貢獻」與 aDPS。
  - **死亡**（第一列，重點標示）：次數（紅色）與每次死亡的時間與致命技能，點擊跳到該時間；沒有死亡時以綠色顯示「沒有死亡」。
  - **比較範圍**：一定從 0:00 開始，不顯示起點。較長一方顯示「到 結束點（之後 N 秒不列入統計）」（各自的時間），沒被裁切的一方只顯示「全場」（戰鬥長度已在選單上）。
  - **開打前**：開打當下身上已有的自身效果（例如武士的明鏡止水、天道、真北，騎士的鋼鐵信念、進食），推知開打前用過的技能。「食物效果時間延長」（含部隊特效版）只延長食物時間、不影響戰鬥，開打前、當下狀態與比較都不顯示。對方沒有的效果以橘色虛線底線標示，滑鼠停留說明。FFLogs 沒有開打前的施放紀錄，所以沒有確切時間，也看不到開打時已經消失的效果。
  - 玩家、職業、戰鬥、擊殺／滅團與戰鬥長度已在上方的選單顯示，不重複列出。
- 表格下方一行說明對齊錨點數與兩場的時間差範圍；有推進差距時接著列出「推進差距：6:31.2 我慢 8.9 秒」（紅色，我較快時為綠色「我快」），點擊跳到該處，滑鼠提示說明。錨點少於 5 個時提示對齊可能不準。
- 沒有職業規則的職業（目前只有青魔道士等非戰鬥職業）提示不區分 GCD／oGCD。

### 建議
依重要性分成「優先」「建議」「參考」三個**分頁**（分頁標籤顯示則數，紅／橘／灰區分），預設顯示最高一級，沒有內容的分頁不顯示，避免頁面過長。每則有標題與說明；可定位到時間點的建議有「查看」按鈕，會移動時間游標並把時間軸捲動到該處。規則見下方「建議規則」。

### 技能窗口
依職業規則（移植自 xivanalysis）檢查「某個效果期間應該做到的事」，兩邊各自評分後並排比較；沒有規則的職業不顯示這一區。
- 表格每列一種窗口（圖示與名稱），「我」「參考」兩欄各顯示「合格數/評分數」與每個窗口的時間標籤：綠色合格、紅色有問題、灰色不評分（到比較範圍結束都還沒結束）。滑鼠停留顯示時段與問題，點擊跳到時間軸（我的時間換算成參考時間）。
- 窗口名稱與問題說明一律用官方繁中名稱：效果名稱、「技能 後 N 秒」（技能觸發的固定時長窗口）或「效果＋效果＋效果」（多個效果同時存在的期間）。問題例如「只打了 7 個 GCD（應 8 個）」「缺少：調停」「碎心箭、死亡箭雨 合計只用了 2 次（應 3 次）」「不應使用：強甲破點突」。
- 時間軸上，每側 GCD 列的底部以同樣顏色的細條標出窗口期間。
- 判定共通規則：
  - 依時間結束的窗口，應打的 GCD 數以窗口長度封頂（窗口 − 0.25 秒能放進幾個 GCD）；依層數結束的（例如明鏡止水）不封頂。
  - 開打後一段時間內開始的窗口視為「開場」，部分規則的要求不同（預設 10 秒；各職業依 xivanalysis 另訂）。

## 比較規則

- **時間軸對齊**：兩場戰鬥的擊殺時間與轉場時間不同，因此不以絕對時間比較，而是以 Boss 的技能施放為錨點，把「我」的時間換算成參考日誌中「同一個機制」的時間。所有比較都以參考時間呈現。轉場後的機制重新以錨點對齊，轉場前的差距不會延續放大。
- **推進差距**：Boss 血量到了才轉場等「推進」時間取決於輸出，兩邊的時間差會在推進點一次跳開、之後維持。兩個錨點之間時間差跳了 3 秒以上，且前後 30 秒內錨點時間差的中位數也差 3 秒以上（排除隨機機制造成的短暫抖動；相距 15 秒內的跳變視為同一次）才算。我較慢推進時，我多花的這段時間在時間軸上會擠在參考很短的時間內。實測呼嘯之劍第一階段結束：騎士基準我慢 8.9 秒、武士基準慢 6.7 秒、黑魔基準慢 11.3 秒；熱舞綠光沒有。
- **比較範圍**：所有統計（GCD、少打 GCD 的時段、技能使用次數、站位、建議）只計算兩場都在進行的時段；較長一方超出的部分沒有比較對象，不列入統計，但時間軸仍完整顯示並標示範圍外。Boss 機制差異只列到較短一方結束。
- **施放時間**：有詠唱條的技能以「開始詠唱」的時間計，被打斷的詠唱不計。
- **GCD**：以遊戲的公共冷卻判定（含舞步、結印等較短的 GCD，以及會觸發公共冷卻的能力如 Meditate）。GCD 間隔取中位數，**上限 2.5 秒**（GCD 最長 2.5 秒）。
- **少打 GCD**：我停手超過 1.5 倍 GCD（且至少多 1 秒）、而參考在同一段（對齊後）仍施放 GCD 時才算；雙方都停手的時段（Boss 無法攻擊等）不算。
- **平均時機**：同一技能兩邊的使用依時間順序配對（相距 30 秒以內才算同一次，可跳過多出的使用），計算我平均早或晚多少；使用 30 次以上的技能（連擊等）不計算。
- **站位差異**：兩人距離超過 8 yalm、持續至少 2 秒。**機制結算時的站位差異**：差異期間有 Boss 機制結算（Boss 施放完成；自動攻擊等頻繁技能不算），且結算當下兩人仍相距超過 8 yalm。若把參考位置以 Boss 或場地中心做左右、前後或點對稱後與我接近（6 yalm 內，且不到原距離一半），且同一種對稱能解釋過半時間，標示「可能是 X 對稱站位」（可能是攻略或分配不同）。
- **Boss 機制差異**：同一時間兩邊施放不同的 Boss 技能 → 不同變化（隨機機制）；只有一邊施放 → 只有我／只有參考。同一技能相差 5 秒內視為同一次機制。自動攻擊等頻繁的技能不比較。

## 建議規則

依重要性（優先／建議／參考）排序。**「優先」只放影響輸出的項目**（死亡、停手、GCD 速度、推進、技能窗口／爆發、輸出技能與爆發藥少用）；減傷、移動與站位最多到「建議」。同等級維持產生順序（死亡 → 停手 → GCD 速度 → 推進 → 技能窗口 → 開打前 → 技能 → 站位）。

| 規則 | 條件 | 等級 |
|---|---|---|
| **死亡**（永遠排第一） | 我在比較範圍內死亡：標題「你死亡了 N 次：避免死亡是最優先的改進」，列出每次的時間與致命技能、死亡到恢復行動共幾秒無法輸出、參考是否也死亡，並明確提醒「不要死亡」；「查看」跳到第一次死亡 | 優先 |
| 停手總結 | 有少打 GCD 的時段 | 共少 ≥ 3 個 GCD 為優先 |
| 個別停手（最多 3 段） | 依參考同段 GCD 數排序；同段兩人平均距離 > 5 yalm 時補充「可能是走位路線不同」；**停手期間我已死亡時**，標題加「（這段期間你已死亡）」，說明改為死亡時間與致命技能並提醒不要死亡 | 參考 ≥ 3 個 GCD 為優先 |
| GCD 較慢 | 比參考慢 > 10 毫秒；估計整場少打的 GCD 數 | 估計 ≥ 3 個為優先 |
| **推進比參考慢** | 每次推進差距一則：「6:31.2 推進比參考慢 8.9 秒」，說明參考與我推進的時間、之後的機制都跟著延後，並建議對照之前的 GCD、技能窗口與爆發；之前有死亡時註明；我較快推進時不提 | 慢 ≥ 8 秒為優先，否則建議 |
| **技能窗口合格率較低** | 每種窗口一則：「X：你 N 次中 K 次合格，參考 …」，列出最常見的 2 個問題與次數，「查看」跳到第一個不合格的窗口；我全部合格或合格率不低於參考時不提 | 比參考低 ≥ 30 個百分點為優先，否則建議 |
| **開打前的準備不同** | 參考開打時身上有、我沒有的自身效果（例如明鏡止水、坦姿、進食） | 建議 |
| 爆發藥少用 | 藥水使用次數較少 | 優先 |
| 輸出能力技少用 ≥ 2 次 | 參考使用 ≤ 30 次的 oGCD | 優先 |
| 輸出能力技各少用 1 次 | 合併為一則 | 建議 |
| 使用了參考沒用的 GCD | ≥ 3 次（例如武士的燕飛，代表離 Boss 太遠） | 建議 |
| 技能平均較晚使用 | 配對 ≥ 2 次、平均晚 > 5 秒 | 建議 |
| **團隊減傷／移動：參考有用、我沒有對應使用** | 參考的使用在我的前後 30 秒內沒有對應，或次數較少；列出參考的使用時間（最多 5 個），「查看」跳到第一個；團隊減傷註明「影響隊友的生存」 | 建議 |
| **團隊減傷／移動：平均較晚使用** | 配對 ≥ 2 次、平均晚 > 5 秒 | 建議 |
| **自身減傷**：少用、時機不同或較晚 | 同上；註明「只要能保住自己即可」 | 參考 |
| **機制結算時站位不同**（最多 5 段） | 非對稱、有機制結算；標題指出機制名稱與時間；依是否同時少打 GCD、距離排序（同時少打的 GCD 由停手建議列為優先） | 建議 |
| 附近沒有機制的站位不同（最多 3 段） | 非對稱、持續 ≥ 5 秒 | 參考 |
| 可能是不同攻略 | 標示為對稱的站位差異合併為一則 | 參考 |
| 輔助技能少用 | 合併為一則 | 參考 |

- GCD 技能（連擊等）的次數差是少打 GCD 的結果，已由停手與 GCD 速度涵蓋，不列為「少用」。
- 與機制差異整合：站位差異或停手時段開始前 10 秒內到結束之間 Boss 機制不同時，建議中註明（同名不同 ID 附上 ID）；該站位差異降為「參考」。
- 建議為**規則式**產生（結果可預期、不需費用）。

## 待辦與未決事項

### 需要使用者確認
- **第一階段的對稱站位判斷是否正確**：武士比較基準中，7:00 前有數段被標為「可能是點對稱／左右對稱站位」（例如 0:48–0:56、3:10–3:41），尚無法驗證是分配不同還是站位錯誤；若誤判多，可改為只在距離很大（例如 > 20 yalm）時才判斷對稱。
- 第二階段的左右相反站位：已知與 Hero's Blow 方向不同同時發生，需使用者以實際攻略確認是機制造成還是攻略不同。
- **Boss 機制差異中「同一機制兩邊相差較久」的處理**：熱舞綠光（BF76r8yKh4wGaYkm #1 vs b3ph7JxjD4BkVL6Q #20）的「4拍節奏」兩邊對齊後差約 13 秒，超過判定同一次機制的 5 秒，因此列成「只有我」與「只有參考」兩列。是否要放寬或合併尚待使用者決定。

### 使用上的已知限制
- 遊戲版本只依繁中服的版本日期判斷；國際服等其他地區的日誌（更新時程不同）版本會判斷錯誤，不在支援範圍。
- 新版本 Boss 技能的名稱是簡中轉繁，用詞可能與遊戲內繁中不同。
- 站位差異門檻 8 yalm、時機配對窗口 30 秒等參數只以比較基準調整過。
- 技能繁中名稱在第一次查詢時可能需要數秒才出現；Boss 名稱同樣先以英文顯示再換成繁中。
- MT／ST 以整場承受的 Boss 普通攻擊傷害判斷；有換坦的戰鬥只反映承受較多的一方，不代表全程。

# 網頁使用流程與設計

本文件描述 FF14 CopyCat 網頁**給使用者的樣子**：使用流程、各區塊呈現什麼、如何操作、判定規則，以及待辦事項與設計變更紀錄。架構、程式實作、資料處理、驗證數據與部署見 [TECH_NOTES.md](TECH_NOTES.md)。

網站：https://pinchiehyu.github.io/FF14CopyCat/

## 網站目標

讓玩家把自己的 FFLogs 日誌與高階玩家的日誌並排比較，依 Boss 機制對齊兩場戰鬥，找出技能循環、減傷、走位與站位上的差異，並給出具體的改進建議。訪客不需要 FFLogs 帳號，貼上連結即可使用。

## 使用流程

1. **貼上兩個 FFLogs 報告連結**：左邊是「我的日誌」，右邊是「參考日誌（高階玩家）」。連結中的 `fight`、`source` 參數會被用來預選戰鬥與角色；輸入過程會等使用者停止輸入約 0.4 秒後才載入。
2. **選擇戰鬥與角色**：每份報告顯示戰鬥下拉選單（每列為 `#編號`、Boss 繁中名稱、戰鬥長度、擊殺／滅團徽章（綠／紅），各欄固定寬度、上下對齊；滑鼠停留顯示英文名稱）與角色下拉選單（角色名與職業繁中名稱徽章，徽章依職能上色：坦克藍、治療綠、輸出紅；不含極限技等假角色）。角色依隊伍位置排序：坦克 → 純治療（白魔、占星）→ 護盾治療（學者、賢者）→ 近戰 → 遠程物理 → 魔法，同組依職業名稱；標準的 2 坦 2 補 4 輸出隊伍會在名字前標上 MT／ST／H1／H2／D1～D4；**MT／ST 依實際坦 Boss 的情況**：承受 Boss 普通攻擊傷害較多的坦克為 MT（資料查到前坦克先不標位置），組成不標準時不標位置。參考日誌只列同職業時，位置仍依整隊判斷。下拉選單為自訂元件，可用滑鼠或鍵盤（上下鍵、Enter、Esc）操作。不顯示報告標題。選擇的優先順序：
   1. 使用者在下拉選單的手動選擇（換戰鬥時角色回到自動選擇）。
   2. 連結中的 `fight`、`source`。
   3. **參考日誌依「我的日誌」自動選擇**：戰鬥選單**只列與我同一個 Boss 的場次**，預設選最後一次擊殺（沒有擊殺則選最後一場）；連結指定的場次不是同一個 Boss 時不採用。報告中沒有同一個 Boss 時，戰鬥與角色選單都顯示「這份報告沒有 X」並停用（與沒有同職業時相同）。角色選單只列出該戰鬥中與我同職業者——**恰好一位時自動選取並鎖定**（選單顯示「已鎖定」，文字與顏色維持正常不淡化，不能改選，也不受參考連結的 source 影響）；兩位以上時選單上顯示「這場戰鬥有 N 位 X，請選擇要比較的對象」，由使用者在其中選擇（連結的 source 是其中一位時預選）；沒有時**選單本身顯示「這場戰鬥沒有 X」並停用**。提示都顯示在選單上，不另外加說明列，避免版面變長。
   4. 都沒有時：戰鬥選最後一場，角色不選。

   目的：使用者通常只要貼上高階玩家的報告連結，其餘自動完成。
3. **檢查是否可比較**：兩場必須是同一個 Boss、同一職業，否則顯示原因（例如「兩位玩家的職業不同（毒蛇劍士 / 武士）」）。
4. **載入與顯示比較結果**：標題為「比較結果」，依序顯示下列區塊。技能名稱先以英文顯示，繁中名稱查到後自動替換。

## 比較結果頁面

### 摘要
- 以**表格**並列「我」與「參考」兩欄（欄標題以橘／藍區分），只列上方選單沒有的資訊：
  - **比較範圍**：各自時間下的 0:00～結束點；較長一方註明「之後 N 秒不列入統計」。
  - **開打前**：開打當下身上已有的自身效果（例如武士的明鏡止水、天道、真北，騎士的鋼鐵信念、進食），推知開打前用過的技能。對方沒有的效果以橘色虛線底線標示，滑鼠停留說明。FFLogs 沒有開打前的施放紀錄，所以沒有確切時間，也看不到開打時已經消失的效果。
  - 玩家、職業、戰鬥、擊殺／滅團與戰鬥長度已在上方的選單顯示，不重複列出。
- 表格下方一行說明對齊錨點數與兩場的時間差範圍；錨點少於 5 個時提示對齊可能不準。
- 沒有職業規則的職業（目前只有青魔道士等非戰鬥職業）提示不區分 GCD／oGCD。

### 建議
依重要性分成「優先」「建議」「參考」三個**分頁**（分頁標籤顯示則數，紅／橘／灰區分），預設顯示最高一級，沒有內容的分頁不顯示，避免頁面過長。每則有標題與說明；可定位到時間點的建議有「查看」按鈕，會移動時間游標並把時間軸捲動到該處。規則見下方「建議規則」。

### 技能窗口
依職業規則（參考 xivanalysis）檢查「某個效果期間應該做到的事」，兩邊各自評分後並排比較；還沒有規則的職業不顯示這一區。
- 表格每列一種窗口（效果圖示與名稱），「我」「參考」兩欄各顯示「合格數/評分數」與每個窗口的時間標籤：綠色合格、紅色有問題、灰色不評分（到比較範圍結束都還沒結束）。滑鼠停留顯示時段與問題，點擊跳到時間軸（我的時間換算成參考時間）。
- 時間軸上，每側 GCD 列的底部以同樣顏色的細條標出窗口期間。
- 目前的規則：
  - **武士・明鏡止水**：應打 3 個連擊技，且只能用月光、花車、雪風、滿月、櫻花。只計算連擊技（刃風、曉風、陣風、士風、風光、月光、花車、雪風、滿月、櫻花）；居合術、燕返、奧義斬浪不消耗明鏡止水，不列入判斷。
  - **騎士・戰逃反應**：應打 8 個 GCD（深仁厚澤不計）；瀝血劍、悔罪、信念之劍、真理之劍、英勇之劍各 1 次；王權劍、贖罪劍、祈告劍、葬送劍、聖靈合計 3 次；榮耀之劍、償贖劍、厄運流轉、調停各 1 次。
  - **騎士・安魂祈禱**：悔罪、信念之劍、真理之劍、英勇之劍各 1 次。

### Boss 機制差異
表格列出兩場 Boss 機制不同的時間點（參考時間，可點擊跳轉）、類型（不同變化／只有我／只有參考）與兩邊的 Boss 技能。說明文字提醒：這些時間點的站位或走位差異可能是機制造成；「只有一邊」常是輸出較高的一方提早轉場而跳過。顯示盡量簡化：
- 同一次攻擊由多個同名技能 ID 組成時（例如熱舞綠光的「四連指向、定格＆播放」同時有 4 個 ID），名稱只顯示一次，各 ID 放在滑鼠提示。
- 同一招的連續結算（兩邊技能名稱與類型相同、間隔 6 秒內）合併成一列，只顯示第一個時間點，不註明範圍或次數。
- 表格中的技能名稱不附 ID。兩邊同名但 ID 不同的變化（例如熱舞綠光最後的「搖擺哈娑」、呼嘯之劍的「群狼劍」左右版本）以虛線底線標示，滑鼠停留顯示「名稱相同但技能 ID 不同，通常是方向或位置不同的版本（#ID）」。建議文字沒有滑鼠提示，仍在名稱後附一個對方沒有的 ID（例如 `群狼劍 #41880`）。

### GCD 概況與少打 GCD 的時段
- 表格：GCD 數、GCD 間隔、空檔總計（我／參考／差距）。GCD 比參考慢 10 毫秒以上時提示可能是技能速度或加速效果的差異。說明空檔含 Boss 無法攻擊的時間，與參考的差距才有意義。
- 「少打 GCD 的時段」清單：`我的時間區間 停手 X 秒；參考在同一段打了 N 個 GCD`，點擊跳到時間軸；時間軸上以紅色區塊標示。

### 技能使用次數
依 **GCD → 非 GCD → 普通攻擊 → 減傷 → 移動** 分成**分頁**（標籤含技能數），空的分組不顯示；每頁的技能以卡片橫向排列（依畫面寬度自動換行），**我比參考少用的技能排在最前面**（少得越多越前面），其餘依次數差距大小排序。減傷與移動技能不論是否為 GCD 都歸在自己的分組；輔助技能（True North 等）與藥水歸在非 GCD。每張卡片：圖示、名稱（滑鼠停留顯示英文）、我／參考／差距（少用時卡片左側與差距以紅色標示）、平均時機（早／晚 X 秒、相同、—）。普通攻擊只在這裡列出、不畫在時間軸；不紀錄的技能不列出。

### 站位比較
- 說明：兩人距離持續超過 8 yalm 的時段數、其中幾段在 Boss 機制結算時仍站在不同位置、幾段可能是對稱站位。**站位差異在機制結算時才有明顯意義**，其餘多半只是移動路線不同。
- **距離折線圖**：整場兩人距離，虛線為 8 yalm 門檻，差異時段以紅色色塊標示（有機制結算者顏色較深，可能對稱者為灰色）；點擊圖表移動時間游標。
- **俯視圖**：北方朝上、格線 5 yalm，顯示我（橘）、參考（藍）、Boss（灰）的位置與前 5 秒軌跡；下方有時間滑桿與當下距離。
- **站位差異清單**：時間區間、最遠距離、「可能是左右／前後／點對稱站位」標籤；有機制結算的差異以紅色標示，並列出「機制：技能名（時間，相距 N yalm）」（最多 3 個，其餘以「等 N 個」表示）。點擊跳轉並捲動時間軸。

### 並排時間軸
- 橫軸為參考日誌的時間，可縮放（10、20、40、80 px/秒）。
- 列：時間尺、Boss（參考；對齊錨點以紫色標示）、參考 GCD、參考 oGCD、我 GCD、我 oGCD（我的施放已依 Boss 機制對齊）。
- 技能以圖示呈現；滑鼠停留顯示「繁中名稱（英文） 原始時間（對齊後時間）」。
- 標示：少打 GCD 的時段（紅色區塊）、我的戰鬥較短時的結束線（紅線）、比較範圍外（虛線與半透明遮罩，標示「比較範圍外」）、共用時間游標（紫線）。點擊時間尺可移動游標。

### 共用時間游標
站位圖、距離圖與時間軸共用同一個時間游標（參考時間）：拖曳滑桿或點距離圖只移動游標；點清單（少打 GCD 的時段、站位差異、Boss 機制差異、建議的「查看」）會同時捲動時間軸到該處。

## 比較規則

- **時間軸對齊**：兩場戰鬥的擊殺時間與轉場時間不同，因此不以絕對時間比較，而是以 Boss 的技能施放為錨點，把「我」的時間換算成參考日誌中「同一個機制」的時間。所有比較都以參考時間呈現。
- **比較範圍**：所有統計（GCD、少打 GCD 的時段、技能使用次數、站位、建議）只計算兩場都在進行的時段；較長一方超出的部分沒有比較對象，不列入統計，但時間軸仍完整顯示並標示範圍外。Boss 機制差異只列到較短一方結束。
- **施放時間**：有詠唱條的技能以「開始詠唱」的時間計，被打斷的詠唱不計。
- **GCD**：以遊戲的公共冷卻判定（含舞步、結印等較短的 GCD，以及會觸發公共冷卻的能力如 Meditate）。GCD 間隔取中位數，**上限 2.5 秒**（GCD 最長 2.5 秒）。
- **少打 GCD**：我停手超過 1.5 倍 GCD（且至少多 1 秒）、而參考在同一段（對齊後）仍施放 GCD 時才算；雙方都停手的時段（Boss 無法攻擊等）不算。
- **平均時機**：同一技能兩邊的使用依時間順序配對（相距 30 秒以內才算同一次，可跳過多出的使用），計算我平均早或晚多少；使用 30 次以上的技能（連擊等）不計算。
- **站位差異**：兩人距離超過 8 yalm、持續至少 2 秒。**機制結算時的站位差異**：差異期間有 Boss 機制結算（Boss 施放完成；自動攻擊等頻繁技能不算），且結算當下兩人仍相距超過 8 yalm。若把參考位置以 Boss 或場地中心做左右、前後或點對稱後與我接近（6 yalm 內，且不到原距離一半），且同一種對稱能解釋過半時間，標示「可能是 X 對稱站位」（可能是攻略或分配不同）。
- **Boss 機制差異**：同一時間兩邊施放不同的 Boss 技能 → 不同變化（隨機機制）；只有一邊施放 → 只有我／只有參考。同一技能相差 5 秒內視為同一次機制。自動攻擊等頻繁的技能不比較。

### 名稱
- **職業名稱**一律以遊戲官方繁中顯示（例如黑魔道士、毒蛇劍士、暗黑騎士）。
- **技能名稱**以繁中顯示：優先用官方繁中；新版本 Boss 技能沒有官方繁中時，以簡中轉繁顯示（使用者決定）；都沒有時沿用英文。滑鼠停留顯示英文名稱。
- **Boss 名稱**（戰鬥名稱）以官方繁中顯示，例如呼嘯之劍；由多個 NPC 組成的名稱（如 `living liquid / liquid hand`）逐段翻譯，查不到的段落（如 Striking Dummy）保留英文。「不是同一個 Boss」的訊息也使用繁中名稱。
- **道具**（例如爆發藥）同樣以官方繁中顯示，HQ 道具加上「（HQ）」，例如「3級剛力之寶藥（HQ）」。

## 建議規則

依重要性（優先／建議／參考）排序，同等級維持產生順序（停手 → GCD 速度 → 技能窗口 → 開打前 → 技能 → 站位）。

| 規則 | 條件 | 等級 |
|---|---|---|
| 停手總結 | 有少打 GCD 的時段 | 共少 ≥ 3 個 GCD 為優先 |
| 個別停手（最多 3 段） | 依參考同段 GCD 數排序；同段兩人平均距離 > 5 yalm 時補充「可能是走位路線不同」 | 參考 ≥ 3 個 GCD 為優先 |
| GCD 較慢 | 比參考慢 > 10 毫秒；估計整場少打的 GCD 數 | 估計 ≥ 3 個為優先 |
| **技能窗口合格率較低** | 每種窗口一則：「X：你 N 次中 K 次合格，參考 …」，列出最常見的 2 個問題與次數，「查看」跳到第一個不合格的窗口；我全部合格或合格率不低於參考時不提 | 比參考低 ≥ 30 個百分點為優先，否則建議 |
| **開打前的準備不同** | 參考開打時身上有、我沒有的自身效果（例如明鏡止水、坦姿、進食） | 建議 |
| 爆發藥少用 | 藥水使用次數較少 | 優先 |
| 輸出能力技少用 ≥ 2 次 | 參考使用 ≤ 30 次的 oGCD | 優先 |
| 輸出能力技各少用 1 次 | 合併為一則 | 建議 |
| 使用了參考沒用的 GCD | ≥ 3 次（例如武士的燕飛，代表離 Boss 太遠） | 建議 |
| 技能平均較晚使用 | 配對 ≥ 2 次、平均晚 > 5 秒 | 建議 |
| **減傷／移動：參考有用、我沒有對應使用** | 參考的使用在我的前後 30 秒內沒有對應，或次數較少；列出參考的使用時間（最多 5 個），「查看」跳到第一個 | 未對應或少用 ≥ 2 次為優先，否則建議 |
| **減傷／移動：平均較晚使用** | 配對 ≥ 2 次、平均晚 > 5 秒 | 建議 |
| **機制結算時站位不同**（最多 5 段） | 非對稱、有機制結算；標題指出機制名稱與時間；依是否同時少打 GCD、距離排序 | 同時少打 GCD 為優先，否則建議 |
| 附近沒有機制的站位不同（最多 3 段） | 非對稱、持續 ≥ 5 秒 | 參考 |
| 可能是不同攻略 | 標示為對稱的站位差異合併為一則 | 參考 |
| 輔助技能少用 | 合併為一則 | 參考 |

- GCD 技能（連擊等）的次數差是少打 GCD 的結果，已由停手與 GCD 速度涵蓋，不列為「少用」。
- 與機制差異整合：站位差異或停手時段開始前 10 秒內到結束之間 Boss 機制不同時，建議中註明（同名不同 ID 附上 ID）；該站位差異降為「參考」。
- 建議為**規則式**產生（結果可預期、不需費用）。

## 待辦與未決事項

### 需要使用者確認
- **第一階段的對稱站位判斷是否正確**：武士比較基準中，7:00 前有數段被標為「可能是點對稱／左右對稱站位」（例如 0:48–0:56、3:10–3:41），尚無法驗證是分配不同還是站位錯誤；若誤判多，可改為只在距離很大（例如 > 20 yalm）時才判斷對稱。
- 第二階段的左右相反站位：已知與 Hero's Blow 方向不同同時發生，需使用者以實際攻略確認是機制造成還是攻略不同。
- **Boss 機制差異中「同一機制兩邊相差較久」的處理**：熱舞綠光（BF76r8yKh4wGaYkm #1 vs b3ph7JxjD4BkVL6Q #20）的「4拍節奏」兩邊對齊後差約 13 秒，超過判定同一次機制的 5 秒，因此列成「只有我」與「只有參考」兩列。是否要放寬或合併尚待使用者決定。

### 使用上的已知限制
- 轉場前後的時間對齊可能差數秒。
- 新版本 Boss 技能的名稱是簡中轉繁，用詞可能與遊戲內繁中不同。
- 站位差異門檻 8 yalm、時機配對窗口 30 秒等參數只以比較基準調整過。
- 技能繁中名稱在第一次查詢時可能需要數秒才出現；Boss 名稱同樣先以英文顯示再換成繁中。
- MT／ST 以整場承受的 Boss 普通攻擊傷害判斷；有換坦的戰鬥只反映承受較多的一方，不代表全程。

### 可能的後續方向
- **開打前的技能使用**：已以開打當下的效果顯示（摘要表格「開打前」）。開打前的確切時間無法取得（實驗結果見 TECH_NOTES.md「開打前的資料」）。開打前詠唱、開打後結算的技能（例如騎士 Lavid 0.36 秒的聖靈）沒有開始詠唱的時間，仍畫在結算時間。
- **依 xivanalysis 擴充技能窗口與職業分析**（已完成武士明鏡止水、騎士戰逃反應與安魂祈禱；細節見 TECH_NOTES.md「xivanalysis 規則移植評估」「技能窗口」）：
  - 其他職業的窗口規則（逐職業移植，技能 ID 以遊戲資料查證）。
  - 冷卻技漂移（冷卻好了沒立刻用）、團隊 Buff 與爆發藥窗口內的技能內容、DoT 覆蓋、Proc 浪費、量譜溢出、身位等其他 xivanalysis 分析。
  - 冷卻技的理論最大使用次數。
- 建議改由 LLM 產生或潤飾（需 API 金鑰與費用）；目前為規則式。
- 死亡、受到的傷害等資料尚未分析。
